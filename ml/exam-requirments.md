Exam project
Requirements. You must:
1. Briefly describe the problem you want to solve
2. Find a dataset (f.ex. from kaggle.com)
3. Prepare the data
4. Train a model 
5. Evaluate the quality of the model


Extras:
Publish the model to a webserver. You can also
demonstrate your project in Colab or any Python editor.


Possible methods:
Supervised Learning:
- Deep Neural Network (previous example: bankcustomer, stay or leave)
- Convolutional Neural Network (previous example: recognize handwritten digits)
- GPT finetuning and inference
Project ideas 
If you want to use any other methods, contact jone@ek.dk for approval.
